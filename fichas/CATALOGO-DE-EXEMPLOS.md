# Catálogo de exemplos — 25 agentes de uma operação real

Uma linha por agente. **Isto não é para instalar**, é para roubar ideias.

Estes 25 correm numa operação comercial que vive de prospecção, CRM e entrega a clientes. A maior
parte tem a lente errada para quem dirige: foram construídos em volta de quem executa, e a lente é
registo, actividade, cadência, caixa de entrada. A tua é conta, receita, equipa, trimestre, decisão.

Serve para uma coisa: quando pensares "devia haver um agente para X", vê se alguém já pensou nisso,
e como. Depois forja a **tua** versão na Oficina, com a tua lente.

| Agente | O que faz | Serve a quem dirige? |
|---|---|---|
| Cérebro | Supervisor, memória, orquestração, oficina | ⭐ É o que tens |
| Agent Master · Agent Manager | Oficina de agentes e auditoria SPAR | ⭐ Fundidos no teu Modo 2 |
| Estratega | Relatório comercial, funil, previsão, por pessoa | ⭐ Ficha O Painel |
| Sentinela | Semáforo do pipeline, alertas vermelhos | ⭐ Ficha O Painel |
| Sombra | Marca pessoal, conteúdo, publicações | 🔸 Se comunicares para fora |
| Design Pro | Apresentações, propostas, dashboards em HTML | ⭐ Ficha Design Pro |
| Transcritor · Intérprete | Chamadas e reuniões para registo estruturado | 🔸 Base da ficha O Cronista |
| Hunter · Garimpeiro · Recruta | Prospecção e criação de oportunidades | ❌ Se não prospectares tu |
| Activator · Ressuscitador | Reactivar contactos frios e negócios perdidos | ❌ Trabalho de equipa |
| Qualifier · Porteiro | Qualificar entradas, gate de respostas | ❌ Operacional |
| Copywriter | Escrita de emails de abordagem | ❌ Operacional |
| Maestro · Organizador | Plano diário de chamadas, distribuição | ❌ Operacional |
| Engenheiro · Escuteiro | Abordagem por email e por rede profissional | ❌ Operacional |
| Argus | Vigia concursos públicos e classifica oportunidades | 🔸 Se o sector o justificar |
| Arquitecto · Construtor · Gervásio | Desenho e âmbito de implementações | ❌ Equipa de entrega |
| Configurador | Prepara ambientes de trabalho para outras pessoas | 🔸 Se replicares isto para a equipa |
| Mesclas | Higiene e deduplicação de dados | ❌ Manutenção |
| Verticais (energia, hospitalidade) | Agentes de um só sector | ❌ Específicos demais |
| Makers (tarefas, telefonia, chat, ponto) | Configuram ferramentas concretas | ❌ Configuração |
| Forjador | Construía automações numa plataforma descontinuada | ❌ Ver metodo/06-LOOPS.md |

**A lição, que vale mais do que a tabela:** vinte destes vinte e cinco não te servem, e nenhum deles
foi mal construído. Foram construídos para outra pessoa. É exactamente por isso que este repositório
não traz uma estrutura pronta.
